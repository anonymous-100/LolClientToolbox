# 看视频 · 切窗

**没有界面，也没有热键。** 这个插件只提供「切到视频 / 切回游戏」这个能力，
由「看视频（自动）」在检测到死亡/复活时调用。功能入口只有自动插件那一张卡片。

> 2026-10-25 用户拍板：「移除手动看视频功能，没有意义」。
> 之前这里是一张卡片 + Ctrl+F8 热键，用来手动切出/切回；现在整条手动链路都删了，
> 只留下自动模式会用到的切窗口、暂停视频、静音游戏。

## 它负责什么

切出时：找到（或启动）浏览器 → 拉到前台 → 恢复视频播放 → 只静音游戏进程
切回时：精确暂停视频 → 恢复游戏声音 → 最小化视频窗口（焦点由系统交还游戏）

## 自动收尾（用户自己 Alt+Tab 回游戏也管）
不经过自动模式、自己 Alt+Tab 切回游戏时，程序会**自动补一次收尾**：
暂停视频 + 恢复游戏声音（视频窗口留在后台最小化，下次直接回来）。
手动切回去以后游戏不会一直哑着——这是「手动切回游戏也自动收尾」这项在管。

## 参数
- **视频网址**：没有浏览器窗口时用它启动；已有浏览器只做聚焦，不会每次多开标签
- **切回时暂停视频**：默认开。靠系统媒体会话精确暂停（已经是暂停就不动它）
- **切出时静音游戏**：默认开。只静音游戏进程，客户端（队伍语音）不动。
  **退出程序时**如果还停在视频模式，会自动把游戏声音放开，不会留下一个哑着的游戏
- **手动切回游戏也自动收尾**：默认开

## 重要前提
Riot 客户端（含游戏）**最好用普通权限运行**。如果客户端是「以管理员身份运行」的，
Windows 会拦住普通权限程序把浏览器拉到前台（UIPI）—— 表现是「切出去了但浏览器没到前面」，
日志里会写「⚠浏览器没抢到前台」。启动时也会自检提示。

## 已知限制
- 拿不到系统媒体会话时（浏览器没在播、系统版本太老）才退回切换式媒体键，
  那种情况下「你手动暂停过」可能被按反
- 静止画面/静音的视频无法判断是否在播，只会按「有没有媒体会话」处理
- 游戏独占全屏时，抢前台可能反复失败（游戏会把焦点抢回去），日志里能看出是这种情况
