# 看视频（手动）

按热键切到视频网站，再按一次把视频窗口最小化回到游戏。适合死了等复活时看两眼。

## 怎么用
1. 进对局后按 **Ctrl+F8**（可在设置里改）→ 浏览器到前台，视频继续播
2. 再按一次 → 视频暂停 + 浏览器最小化，焦点自动回到游戏

## 自动收尾（不用按热键也行）
如果你不按热键、自己 Alt+Tab 切回游戏，程序会**自动补一次收尾**：
暂停视频 + 恢复游戏声音（视频窗口会留在后台最小化，下次一键就回来）。
手动切回去以后游戏不会一直哑着——这是「手动切回游戏也自动收尾」这项在管。

## 参数
- **视频网址**：没有浏览器窗口时用它启动；已有浏览器只做聚焦，不会每次多开标签
- **切换热键**：如 Ctrl+F8 / Alt+Shift+V，改完立刻生效
- **切回时暂停视频**：默认开。靠系统媒体会话精确暂停（已经是暂停就不动它）
- **切出时静音游戏**：默认开。只静音游戏进程，客户端（队伍语音）不动
- **手动切回游戏也自动收尾**：默认开。自己 Alt+Tab 回游戏时自动暂停视频、恢复游戏声音

## 重要前提
Riot 客户端（含游戏）**必须以普通权限运行**。如果客户端是「以管理员身份运行」的，
Windows 会拦住普通权限程序的全局热键、前台切换和键盘读取 —— 表现就是「热键完全没反应」。
启动时日志会自检并提示这一条。

## 已知限制
- 拿不到系统媒体会话时（浏览器没在播、系统版本太老）才退回切换式媒体键，
  那种情况下「你手动暂停过」可能被按反
- 静止画面/静音的视频无法判断是否在播，只会按「有没有媒体会话」处理
