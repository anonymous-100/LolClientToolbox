# 看视频（自动）

对局里**死了就自动切到视频网站，复活自动切回游戏**。不用按任何键。

这张卡片**本身就是一个开关**：点一下卡片（或右边的小轨道）＝开 / 关，没有「只触发一次」的按钮 ——
2026-10-25 用户拍板，切出去看视频这种事手动按一次没有意义。

它和「看视频 · 切窗」是两个插件：本插件只负责**判断死没死**，
真正切窗口、暂停视频、静音游戏都由切窗插件去做（本插件不碰任何窗口）。
所以两个插件要一起用；切窗插件没装或被禁用的话，本插件只记录日志、不会替你切。

## 怎么用

1. 两个插件都启用（默认就是这样），卡片右侧开关显示「ON / 守护中」
2. 进对局 → 死了会自动切到浏览器 → 复活倒计时归零自动切回
3. 不想用了：点一下卡片就能关（开关会变 OFF，并写进设置，重启后仍然是关的）。
   如果关的瞬间你正在看视频，它会先把你送回游戏再关

## 数据从哪来

- **主**：官方 Live Client Data API（`https://127.0.0.1:2999`）的 `allgamedata`。
  ⚠ 复活倒计时（`respawnTimer`）**不在 activePlayer 里，在 `allPlayers[]` 里**
  （2026-10-25 真机实测，网上教程写的 activePlayer.respawnTimer 是错的）。
  程序会先用 `activePlayer` 的名字认出「哪个人是你」，再读你的倒计时：
  大于 0 就是死了，数值是还要等几秒 —— 精确，且是 Riot 给第三方用的官方接口
- **兜底**：上面那个接口取不到时，改看**自己的屏幕**：英雄死后画面会被去色（灰屏），
  再 OCR 画面中下部读倒计时秒数

## 参数

- **自动看视频**：总开关，和卡片上的开关是同一个
- **至少还剩几秒才切出**：默认 8 秒。死亡瞬间读到的就是总时长，低于门槛不切（来回切更烦）
- **Live 接口挂了用屏幕兜底**：默认开
- 其余（端口、端点、取样区域、灰屏阈值）在设置窗的「开发者选项」里
- 视频网址、静音、切回暂停这些在**「看视频 · 切窗」**那一栏里

## 重要前提

- **客户端要用普通权限启动**。如果是「以管理员身份运行」的，切窗口会被 Windows 拦
  （UIPI），判断得再准也切不动 —— 切出时日志会写「浏览器没抢到前台」

## 死了却没跳转？按顺序查这四条

1. **先看开关是不是 ON**：卡片右侧写 OFF 就是被关了（点卡片关、设置窗取消勾选都会关）
2. **看跑的是哪份构建**。日志第一行会写「启动 程序目录 …」；往下数「已加载 N 个功能插件」，
   有本插件才是 7 个。仓库里常同时存在 `.dev` / `.dev-new` / `dist` 好几份，
   跑着旧构建时「功能明明写了却不生效」特别难看出来（2026-10-25 踩过一次）
3. **端点必须是 `allgamedata`**。2026-10-25 真机实测：`respawnTimer` 不在
   `/liveclientdata/activeplayer` 里（该端点压根没有死亡信息），只在 `allPlayers[]` 中。
   填错的表现是日志一直说「Live 接口取不到」，然后一直不切
4. **看日志里「切出看视频」那一行**：
   - 没这行 → 没判出死亡（看上面第 3 条与灰屏阈值）
   - 有这行但紧接着出现「关闭视频（自动 · 前台是 league of legends · 切出后 X s）」→
     是游戏把焦点抢回去了（客户端提权运行），或者你自己 Alt+Tab 回去了

## 已知限制

- **屏幕兜底是估算**：OCR 读不到精确倒计时时按 `assumedRespawnSec`（默认 15 秒）估，
  可能早一点或晚一点切回。主模式（Live 接口）是精确的
- **灰屏阈值要对局校准**：2026-10-25 真机实测活着时整窗平均饱和度约 84；
  默认阈值 40 是按「死后整屏去色会大幅下降」推的，还没量过真实死亡画面 ——
  判不出死亡就调高、没死就误判就调低。读数在日志里（判出死亡时会写饱和度与阈值），
  也可以用 `dotnet run --project tools/probe` 的屏幕检查项离线量
- **独占全屏抓不到画面**：屏幕兜底靠 GDI 截屏，独占全屏时画面不进 GDI，
  会报「屏幕兜底采不到画面」。无边框/窗口化正常
- 大乱斗（ARAM）等模式的复活时间更长，门槛可以相应调高
