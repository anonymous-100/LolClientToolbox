# 看视频（自动）

对局里**死了就自动切到视频网站，复活自动切回游戏**。不用按任何键。

它和「看视频（手动）」是两个插件：本插件只负责**判断死没死**，
真正切窗口、暂停视频、静音游戏都由手动版去做（自动版不碰任何窗口）。
所以两个插件要一起用；手动版没装或被禁用的话，本插件只记录日志、不会替你切。

## 怎么用

1. 两个插件都启用（默认就是这样）
2. 进对局 → 死了会自动切到浏览器 → 复活倒计时归零自动切回
3. 想确认它有没有读到数据：**点一下这张卡片**，会立刻采样一次，把结果写在底部状态行和日志里

## 数据从哪来

- **主**：官方 Live Client Data API（`https://127.0.0.1:2999`）的 `allgamedata`。
  ⚠ 复活倒计时（`respawnTimer`）**不在 activePlayer 里，在 `allPlayers[]` 里**
  （2026-10-25 真机实测，网上教程写的 activePlayer.respawnTimer 是错的）。
  程序会先用 `activePlayer` 的名字认出「哪个人是你」，再读你的倒计时：
  大于 0 就是死了，数值是还要等几秒 —— 精确，且是 Riot 给第三方用的官方接口
- **兜底**：上面那个接口取不到时，改看**自己的屏幕**：英雄死后画面会被去色（灰屏），
  再 OCR 画面中下部读倒计时秒数

## 参数

- **自动检测死亡**：总开关。关掉后只检测、不切换
- **至少还剩几秒才切出**：默认 8 秒。死亡瞬间读到的就是总时长，低于门槛不切（来回切更烦）
- **Live 接口挂了用屏幕兜底**：默认开
- 其余（端口、端点、取样区域、灰屏阈值）在设置窗的「开发者选项」里

## 重要前提

- **客户端要用普通权限启动**。如果是「以管理员身份运行」的，手动版切窗口会被 Windows 拦
  （UIPI），自动版判断得再准也切不动 —— 启动时日志会提示这一条
- 视频网址、热键这些仍在**手动版**的设置里，本插件不管

## 已知限制

- **屏幕兜底是估算**：OCR 读不到精确倒计时时按 `assumedRespawnSec`（默认 15 秒）估，
  可能早一点或晚一点切回。主模式（Live 接口）是精确的
- **灰屏阈值要对局校准**：2026-10-25 真机实测活着时整窗平均饱和度约 84；
  默认阈值 40 是按「死后整屏去色会大幅下降」推的，还没量过真实死亡画面 ——
  判不出死亡就调高、没死就误判就调低，点卡片能看当前饱和度
- **独占全屏抓不到画面**：屏幕兜底靠 GDI 截屏，独占全屏时画面不进 GDI，
  会报「屏幕兜底采不到画面」。无边框/窗口化正常
- 大乱斗（ARAM）等模式的复活时间更长，门槛可以相应调高
